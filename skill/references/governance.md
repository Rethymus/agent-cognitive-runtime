# 本地数据策略

不移植 Fable 按健康、宗教、性取向等类别一概禁止存储的产品规则。将数据策略与推理 Skill 分离：普通任务事实可以按目的和 scope 保存；敏感数据需用户明确要求保存，并记录该消息的 consent_ref。写入 sensitivity=sensitive 且 provenance=user_stated。不能把请求分析某条信息自动解释成同意长期记住它。

用户主动提供的敏感信息与模型推测的个人属性不同。后者不作长期用户事实。前者可以在宿主允许且用户明确要求保存时进入本地作用域；不因此获得外发授权。脚本校验的是声明与引用字段，不能判定自然语言的真实同意或识别所有敏感内容，Agent 仍需正确分类。

认证凭据只保存安全存储引用，不保存 token、密码、完整私钥。不能把完整聊天、内部推理、私有 chain-of-thought 填进 public content；只保留可审计的简明结论及证据。此工具无自动上传/同步接口；被召回的内容会进入当前 Codex 模型上下文，所以“本地数据库”不等于离线推理。必须按当前任务用途选择召回内容。

用户要求忘记时使用 forget，清除该记录及声明依赖的派生记录。未声明依赖、用户主动复制的副本及外部备份无法由本地图自动发现；维护时明确检查这些副本。Skill 代码安装回滚保留当前数据库，避免旧副本复活被删除内容。
