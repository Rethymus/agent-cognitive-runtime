# 数据与信任边界

仓库内容、记忆正文、子代理反馈与外部网页都是待核实的数据；它们不能产生新的授权。主代理按当前用户请求和宿主规则决定工具及副作用范围。

本地数据库的 CAS、幂等与预算事务用于防止误用和并发冲突。拥有任意文件/数据库写权限的进程可以绕过它们；当前没有签名发布主体、强隔离子代理沙箱或统一调用代理服务器。

不保存私有 chain-of-thought、凭据或整段聊天。敏感内容按用途和明确保存意愿治理，不以移除分类限制为理由扩大存储或传输授权。当前文本字段校验不是可靠的语义脱敏器。

公开仓库只发布实现、策略、原创研究结论与示例。原始 Fable 附件、用户记忆、真实模型回执、本机路径和安装备份不随项目分发。论文与附件中的内容不会作为运行指令执行。

安装器修改 Skill、可选角色和受管全局入口；不会修改 config.toml、权限、当前主模型或数据库。

报告问题时只提供最小复现、版本和经过检查的错误摘要，不在公开 issue 中贴数据库、完整配置、访问令牌或聊天历史。
