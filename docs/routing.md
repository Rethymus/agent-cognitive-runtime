# 双向路由与推理预算

操作协议见 [Skill 路由说明](../skill/references/adaptive-routing.md)，研究依据见 [路由研究](research/adaptive-routing.md)。

具体模型 ID 在 model-registry.json；角色职责和 effort 在 subagent-policy.json；特征门槛、预算、核验合约在 adaptive-routing.json。不要把模型名称写入路由算法。新模型支持范围和效果需要重新核对；同名 effort 不表示相同能力或成本。

冷启动阶段使用规则门控，不输出经过校准的成功概率。未知先做有界只读探测，环境失败先修环境。强决策只返回当前阻碍的合约，降级须有核验后的检查点。主代理负责核对证据，脚本不能判断引用是否真实。

每个任务 4 次子代理新推理轮次，强模型最多 2，frontier 最多 1，max 最多 1，在途最多 3。默认值是起点；修改配置不能悄悄扩大正在执行任务的最初上限。所有准入只覆盖走本接口的调用，不提供整个 Codex 的 token 硬限额。

Luna 作为子代理发现复杂点，向父代理汇报；父代理派同级决策代理，不递归创建团队。已有合适强主代理时优先自行作有界决策。经济型主代理遇到严格顺序阻塞且宿主不能委派时，明确返回宿主交接需求。
