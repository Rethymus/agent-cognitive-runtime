# 研究导航

本目录区分原始材料观察、论文结论、工程建议与实现证据。外部文献没有被完整复现；读取深度见 sources.json。论文中的提升不等于本系统测得的提升。

1. [认知运行时基础设计](foundations.md)：机制迁移、记忆、验证、自学习和目标架构；保留历史 v0.1 语境。
2. [自适应路由研究](adaptive-routing.md)：难度判断、模型×effort、双向交接与预算。
3. [附件迁移说明](attachment-review.md)：规则处置、原文缺席时的证据边界。
4. [参考仓库分析](reference-repository.md)：README、目录、协议与代码样本如何影响本项目组织。
5. [来源目录](sources.json)：研究来源、日期与读取深度；其中产品页不认证用户附件。

新增路由资料也直接链接在路由研究中，日期与论文/预印本身份分别说明。参考项目以固定提交记录，不把其 README 的自述等同于本次端到端验证。
