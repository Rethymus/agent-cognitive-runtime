# 研究导航

本目录区分原始材料观察、论文结论、工程建议与实现证据。外部文献没有被完整复现；读取深度见 sources.json。论文中的提升不等于本系统测得的提升。

1. [认知运行时基础设计](foundations.md)：机制迁移、记忆、验证、自学习和目标架构；保留历史 v0.1 语境。
2. [自适应路由研究](adaptive-routing.md)：难度判断、模型×effort、双向交接与预算。
3. [附件迁移说明](attachment-review.md)：规则处置、原文缺席时的证据边界。
4. [2026 年 9 月深度证据审查](evidence-review-2026-09.md)：难度估计成本、教师兼容性、记忆负收益、评审与评测污染；含反证与适用边界。
5. [证据映射](evidence-map.json)：10 条可追踪主张，关联来源、限制和反驳条件。
6. [持续研究与开发流程](development-program.md)：让后续 Agent 按证据更新、评测与回滚。
7. [研究实验协议](../../evals/research-program.json)：8 组待运行实验；执行前置参数尚需确定。
8. [来源目录](sources.json)：研究来源、版本、日期与读取深度；其中产品页不认证用户附件。

新增路由资料也直接链接在路由研究中，日期与论文/预印本身份分别说明。研究方法与实验结果分别核对，不将论文作者报告视为本项目实测。
