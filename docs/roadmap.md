# 后续路线

优先真实任务评测与可观察用量，再扩展学习型路由。每项可独立交付、验证和回滚。

- M1 已实现：本地记忆、CAS、检查点、候选隔离。
- M2 已实现：角色配置、自适应准入、双向交接指导、安装回滚。
- M3 待做：任务族配对 fixtures、隐藏集、完整根/子用量与延迟记录。
- M4 待做：主/子统一派发适配器，预算中止、真实回执与恢复对账。
- M5 待做：基于足够数据校准模型×effort 路由，未知/OOD 回退与新模型锚点评测。
- M6 待做：隔离验证器、独立发布权限、带签名的 candidate 晋升与撤销。

M3 之前不承诺质量接近强模型或成本下降；M4 之前不承诺全局 token 硬封顶；M6 之前不启用候选自行改写 Skill。优先删去没有实证收益的流程，而不是不断添加监督模型。
