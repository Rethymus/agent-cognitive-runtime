# 评测设计与证据等级

程序测试证明输入校验、版本冲突、预算、回滚等可执行约束。任务场景文件定义实验，但不是实验结果。真实模型调用 smoke 只能证明特定一次调用，不证明整体能力或成本优势。

目标比较：Luna/xhigh、Luna/max、Sol/high、Astra/high 单代理，固定强主代理＋Luna，以及自适应 Harness。模型绑定可替换；对比时保持任务输入、工具、验收与预算可比。

按局部执行、跨组件修复、多约束决策、开放研究、上下文恢复、环境故障和模糊任务分层，分离开发、校准和隐藏回归集。每族约 30 个初始配对样本可检查趋势，不保证统计功效；报告样本量与区间。失败稀少时另做压力测试，不能以零观察错误保证可靠。

统计完成率、严重错误、错误降级、无益升级、返工、全成本和 P50/P95 延迟。成本含主代理监督与上下文传递；实际回执缺失用 null/unknown，不填零。

没有运行的候选模型结果为 unknown。只使用被选模型反馈会产生选择偏差；用有限、低风险配对试验补足证据。没有真实采样概率和覆盖条件时，不声称离线反事实估计无偏。

文件：`evals/scenarios.jsonl` 为历史目标场景，`evals/experiment.json` 为目标对照设计，`evals/run-record.template.json` 为新真实运行记录模板。早期九组变体与当前双向路由实验不是完全相同的实验，应分别编号、冻结协议后运行。

只有独立验证、留出集与可回滚发布流程齐备后才能考虑 candidate → verified → promoted。当前晋升关闭，不运行自动模型基准或付费探索。
